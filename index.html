Iqbal Habibi

Web Developer

Universitas Muhammadiyah Purwokerto

Saya Iqbal Habibi, mahasiswa aktif yang serius menekuni dunia web development. Bagi saya, ngoding bukan sekadar hobi — ini adalah cara saya berkontribusi dan menciptakan solusi nyata di sekitar saya.

Perjalanan saya dimulai dari rasa penasaran sederhana tentang "bagaimana website itu bisa hidup?" dan kini berkembang menjadi passion yang mendalam — mulai dari membangun sistem kasir untuk UMKM lokal, platform edukasi interaktif untuk anak SD, hingga dashboard visualisasi data kesehatan.

Saya percaya setiap baris kode adalah kesempatan untuk belajar sesuatu yang baru. Dengan mindset growth dan semangat yang tidak pernah padam, saya terus bergerak maju.

Mulai Belajar Web Dev 2023

Memulai perjalanan dengan HTML, CSS, dan JavaScript dasar. Membuat proyek pertama berupa halaman web sederhana.

Proyek Nyata Pertama 2024

Ekspansi ke React & Vercel 2025

Aktif di CodingCamp, membangun proyek edukasi dan game interaktif. Mulai menggunakan React dan deploy otomatis via Vercel.
